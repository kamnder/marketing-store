# For You — متجر العطور والجمال

تطبيق Flutter بواجهة عربية RTL لمتجر **For You** للعطور ومستحضرات التجميل والعناية بالبشرة.

## الموجود حالياً
- واجهة متجر بدرجات البني والذهبي.
- البحث عن المنتجات والتصفح حسب الأقسام.
- منتجات وأسعار تجريبية بالجنيه المصري قابلة للتعديل.
- سلة مشتريات مع تعديل الكميات وحساب الإجمالي.
- نموذج بيانات التوصيل والتحقق من الحقول.

## التشغيل
```bash
flutter pub get
flutter run
```

## بناء APK
من تبويب **Actions** شغّل **Build For You Android APK**، ثم نزّل artifact باسم **For-You-Android-APK** عند نجاح البناء.

## مهم قبل الإطلاق
المنتجات والأسعار تجريبية. نموذج الطلب لا يرسل الطلب إلى المتجر حتى الآن. لاستقبال الطلبات فعلياً نحتاج رقم واتساب المتجر أو ربط قاعدة بيانات وخدمة خلفية.
